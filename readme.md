# 📋 작업 리스트 (Todo App)

## 📌 프로젝트 개요
사용자가 일상의 작업을 효율적으로 관리할 수 있는 Web 기반의 Todo 애플리케이션입니다.

## 🎯 목표
- 할일을 쉽게 추가하고 관리할 수 있는 기능 제공
- 깔끔하고 직관적인 사용자 인터페이스 제공
- 라이트/다크 모드 지원

## 📂 프로젝트 구조
```
codespaces-blank/
├── index.html          # 메인 Todo 애플리케이션 (이 파일에서 개발)
└── readme.md           # 프로젝트 문서
```

## ⚙️ 기능 요구사항

### 1. 기본 기능
- ✅ 할일 입력 (textbox와 추가 버튼)
- ✅ 할일 목록 표시
- ✅ 완료 표시 (체크박스)
- ✅ 할일 삭제

### 2. UI/UX 개선
- ✅ 입력창과 버튼을 상단에 고정 (sticky header)
- ✅ 제목을 "작업 리스트"로 표시
- ⬜ 라이트/다크 모드 전환 버튼 (예정)

## 🛠️ 작업순서

### 진행 중
1. 할일을 입력할 textbox, 입력 버튼 생성 (완료)
2. textbox, 입력 버튼을 상단에 고정 (완료)
3. 제목을 "작업 리스트"로 설정 (완료)
4. 라이트/다크 모드 전환 버튼을 가장 위쪽에 추가 (완료)

## ⚠️ 개발 주의사항
- `index.html` 파일에만 작성합니다.
- 작업순서 또는 작업요청에만 해당하는 코드를 추가합니다.
- 완료한 작업은 작업순서 항목에 "(완료)" 표시를 추가합니다.

## 📝 사용 방법
1. 페이지를 열면 할일 입력창이 표시됩니다.
2. 입력창에 할일을 입력하고 "추가" 버튼을 클릭 (또는 Enter 키)
3. 할일이 목록에 추가됩니다.
4. 체크박스로 완료 표시 가능
5. "삭제" 버튼으로 항목 제거
